# Roadmap

## Milestone 0 — Foundation

Status: **implemented in the initial repository bootstrap**.

- pin EAI Core 0.5.4;
- add canonical conformance suite;
- define `learning_case`, `learning_event`, `evidence_record`;
- create append-only event store;
- block real/synthetic event mixing;
- add schema and core integrity tests.

## Milestone 1 — Deterministic EAI runtime

- phase router;
- explicit target-operation requirement before task-density classification;
- evidence-fit handling;
- claim gates for supported performance, independence, retention and transfer;
- didactic gates for scaffold takeover, weak adaptation, learner self-judgment ordering and support fading;
- inspectable gate decision log.

## Milestone 2 — Tutor policy loop

- candidate intervention contract;
- tutor proposes, gate engine allows/modifies/blocks;
- learner must act again after support;
- support-history and fading events;
- no direct mastery write by an LLM.

## Milestone 3 — Synthetic learner testbench

- explicit epistemic state;
- scoped misconceptions;
- latent state hidden from tutor/runtime;
- observation channel;
- counterfactual runs using the same learner seed under different policies;
- simulation outputs labelled as simulation only.

## Milestone 4 — Evidence UI

- event timeline;
- actor ownership of cognitive work;
- observed / derived / unknown / simulated distinction;
- teacher-facing evidence view without fake precision.

## Milestone 5 — Research harness

- compare policies;
- adversarial cases;
- calibration against human learner data before external effect claims;
- separate outcomes for performance, independence, retention, transfer, efficiency and perception.
